# Design skills

These skills are vendored from [jakubkrehel/skills](https://github.com/jakubkrehel/skills) at commit `a72290d140249813898ba8648becf6415abcb059`. They are MIT licensed by Jakub Krehel. The license text is in [LICENSE](LICENSE).

The files are copied unchanged. Only the Markdown is vendored; the per-agent `agents/` folders are left out.

| Skill                  | Use it for                                          |
| ---------------------- | --------------------------------------------------- |
| `variant`              | Exploring visual directions and mockups             |
| `better-layout`        | Spacing, grouping, alignment and responsive layout  |
| `better-typography`    | Type scale, wrapping and font details               |
| `better-colors`        | Palettes, tokens and contrast                       |
| `better-ui`            | Surfaces, icons and motion                          |
| `better-writing`       | Copy                                                |
| `better-interface`     | A broad interface review                            |
| `better-accessibility` | The accessibility pass                              |
| `interface-review`     | The check before opening a pull request that has UI |

`afk`, `break`, `build-design`, `explain-interface` and `state-machine` are not vendored. This site has no use for them yet.

To update, copy the same folders from a newer upstream commit and change the commit above.
