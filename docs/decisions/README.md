# Decision records

Short notes on calls that are not obvious from the code. One file per decision, named `NNNN-title.md`, numbered in order.

Each record has four parts: **Status** (accepted or superseded by NNNN), **Context**, **Decision**, **Consequences**. Keep it under a page.

Add a record when you change a rule in [AGENTS.md](../../AGENTS.md), move a boundary in [ARCHITECTURE.md](../ARCHITECTURE.md), or add a runtime dependency. Do not edit an accepted record to reverse it; write a new one that supersedes it.
